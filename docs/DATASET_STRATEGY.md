# Dataset Strategy

## Primary target: COGITO

COGITO is the main dataset because the same people completed intensive practice across many sessions in working-memory, perceptual-speed and episodic-memory tasks, with additional transfer measures.

Priority pairs:

- spatial 3-back → numerical 3-back;
- numerical memory updating → spatial memory updating;
- alpha span → animal span.

Cross-construct work will begin with perceptual/evidence-processing learning and working-memory learning, using episodic memory as a comparator.

## Open development data

Use open longitudinal datasets to build the pipeline while COGITO access is arranged. OpenCogData is the main discovery catalogue. Prioritise repeated-session datasets with trial-level accuracy/RT and multiple tasks in the same people.

## Derived features

For each person, task and session/window derive accuracy or signal-detection score, median RT, robust RT variability, local learning slope, nonlinear learning-curve parameters and flattening/change-point estimates.

Do not commit restricted third-party raw data to this repository.
