# Hypotheses

## H1 — Construct portability

Learning-curve parameters from a trained task predict improvement on an untrained task that preserves the central cognitive operation while changing the surface or material.

Primary test: does learning dynamics explain transfer beyond baseline score and final trained-task performance?

## H2 — General learnability

Person-level learning parameters covary across tasks and constructs, supporting a common learnability component in addition to construct-specific effects.

Candidate parameters include early slope, nonlinear rate, flattening point, asymptote and residual variability.

## H3 — Cross-construct facilitation

Earlier improvement in construct A predicts greater subsequent learning velocity in construct B after controlling prior B performance, time or session, and person-level differences.

The reverse model B to A must be fitted as a directional comparison.

## H4 — State-sensitive transfer

When sufficient longitudinal resolution exists, transfer should be better predicted by where a learner is in the acquisition trajectory than by current score alone.

## Falsification checks

The strongest proposal is weakened if only concurrent correlations appear, directional effects vanish with controls, effects depend on one task only, or endpoint performance predicts transfer as well as learning dynamics.
